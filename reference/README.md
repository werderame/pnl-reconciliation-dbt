# Public reference material

export/ contains normalised copies of the five supplied SQL/YAML pairs. These files are evidence and are deliberately outside dbt's model paths.

Some descriptions conflict with the SQL, and the exported BOM YAML has a malformed version field. They are retained as reference, not executed as project configuration. Use models/schema.yml and docs/business_rules.md for the executable demo contract.

See docs/provenance.md for identifier and contact-metadata normalisation and reference/portability for the small SQL adapter changes.
